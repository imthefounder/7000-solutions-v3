# Contributing to 7000 Solutions

Thanks for building with us! 7000 Solutions is an open-source civic platform —
citizens use it, developers build it, cities run it.

## Ways to contribute

1. **Add or improve solutions** — the catalog is generated by
   `scripts/generate_solutions.py` (see README). If a solution in your city is
   missing or wrong, open an issue or PR.
2. **Write/improve build guides** — every solution has a step-by-step
   implementation guide (`solution_guides` table, generated by
   `scripts/deepen_solutions.py`). Guides with real local costs, timelines, and
   partner names are the most valuable edits.
3. **Ship features** — the app is Next.js 14 + Supabase. Check the issues tab,
   fork, build, and open a PR.
4. **Report bugs** — include the page, what you did, and what happened.

## Development setup

```bash
npm install
npm run dev
# http://localhost:3000
```

Environment variables (see `.env.example`): Supabase URL/anon key + service
role key for local development. No API keys are required to run the app —
semantic search falls back to keyword matching without `OPENAI_API_KEY`.

> Windows note: run `npm run build` via `scripts/build.cmd` (git-bash mangles
> the PATH for npm's cmd shims).

## Database changes

Migrations live in `supabase/migrations/` (numbered SQL files). Apply them to
your Supabase project via the SQL editor or `supabase db push`. Never edit an
applied migration — add a new numbered file.

## Style

- TypeScript, strict where practical; components in `src/components/ui/`
- Tailwind utility classes; design tokens (glass, chips, gradients) live in
  `src/styles/globals.css` — reuse them instead of adding one-off styles
- Keep the anonymous visitor flow working: no feature should require sign-in

## Content pipeline

- `scripts/generate_solutions.py` — catalog generation (LLM, batched, resume-safe)
- `scripts/deepen_solutions.py` — long descriptions + step-by-step guides
- `scripts/backfill_embeddings.js` — semantic search embeddings (needs OpenAI key)
- `scripts/seed.js` — the 21 hand-written starter solutions
